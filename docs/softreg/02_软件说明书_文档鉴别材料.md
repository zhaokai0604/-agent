## 1. 软件概述

### 1.1 软件名称

`ThreshCore智能日志分析与可控运维平台软件`

### 1.2 软件简称

`ThreshCore`

### 1.3 软件版本

`V1.0`

### 1.4 软件定位

本软件是一套面向日志分析、智能运维、巡检审计与可控 Agent 执行的 B/S 平台。软件将日志分析、智能对话、受控工具调用、安全门控、审计留痕、工作流记忆和知识库检索整合在统一控制台中，既支持传统日志分析任务，也支持通过中文对话触发巡检、诊断和受控运维操作。

## 4. 软件主要功能

### 4.1 日志分析功能

本软件支持日志上传、日志清洗、模板提取、异常检测、结果查看和报告导出。

日志分析相关能力包括：

- 上传日志文件
- 对原始日志进行预处理和脱敏
- 在线日志模板解析
- 异常关键词、突发频次、严重等级与上下文综合评分
- 聊天式日志分析与 AI 辅助诊断

主要实现依据：

- [LogAnalysisController.java](../../src/main/java/com/award/log/controller/LogAnalysisController.java)

### 4.4 安全门控与确认执行功能

软件对 MCP 与 Agent 的写类操作提供统一安全门控机制，用于降低误执行和越权风险。

安全门控主要内容包括：

- 工具名合法性校验
- 工具注册校验
- 只读会话面限制
- 参数规模与单字段长度限制
- Prompt Injection 检测
- 自然语言意图风险判断
- 路径敏感度评分
- 命令模式评分
- 运行时权限评分
- 中风险转人工确认执行
- 高风险直接阻断

确认执行机制还包含：

- 待确认任务缓存
- 请求者绑定
- 过期控制
- 服务端快照确认

## 5. 软件操作流程

### 5.1 启动流程

1. 初始化数据库，执行 `src/main/resources/schema.sql`
2. 配置数据库连接与 AI Key 等敏感参数
3. 启动后端服务
4. 启动前端控制台
5. 登录系统后进入统一控制台

### 5.2 日志分析流程

1. 用户上传日志文件
2. 系统完成日志读取与预处理
3. 调用模板解析与异常检测逻辑
4. 返回日志分析任务结果
5. 用户查看明细、统计和导出内容

### 5.3 运维工具执行流程

1. 用户在 Agent 页面或 MCP 控制台发起请求
2. 系统解析意图或工具参数
3. 安全门控进行风险评估
4. 对低风险操作直接执行或预览
5. 对中风险操作生成待确认记录
6. 对高风险操作直接阻断
7. 全流程写入审计表

### 5.4 AWM 记忆流程

1. 系统记录成功运维轨迹
2. 对轨迹进行评估与归纳
3. 生成结构化 Workflow
4. 存入工作流记忆表
5. 后续同类请求优先命中工作流并复用

## 9. 软件特点总结

本软件具有以下特点：

1. 将日志分析、运维对话、工具调用和审计闭环集成于统一平台
2. 既支持传统日志分析，也支持受控 Agent 运维辅助
3. 通过安全门控、确认执行与审计落库降低工具执行风险
4. 通过 AWM 归纳与复用成功工作流，提升处置复用能力
5. 支持在 Windows 开发环境与 Linux/麒麟生产环境中部署运行
