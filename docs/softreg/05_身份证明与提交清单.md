# 身份证明与提交清单

## 一、按官方要求需要准备的材料类型

根据《计算机软件著作权登记办法》第九条至第十一条，建议至少准备：

1. 软件著作权登记申请表
2. 程序鉴别材料
3. 文档鉴别材料
4. 申请人身份证明
5. 权利归属相关证明文件

官方依据：

- https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html

## 二、当前项目已完成的材料

本目录下已经生成或起草完成：

- 申请表填写稿
- 软件说明书
- 权利归属与合作开发说明
- 非职务开发说明模板
- 程序鉴别材料

## 三、仍需人工补齐的材料

### 1. 若著作权人为自然人

每位著作权人需准备：

- 身份证正反面复印件
- 本人签字页
- 联系电话
- 邮箱
- 通讯地址

### 2. 若著作权人为单位

需准备：

- 营业执照或事业单位法人证书复印件
- 统一社会信用代码
- 加盖公章的申请文件
- 经办人身份证明
- 经办人授权委托书

### 3. 若存在合作开发或权利约定

建议准备：

- 合作开发协议
- 项目任务书
- 竞赛立项或参赛证明
- 单位同意申报说明

## 五、特别提醒

### 1. 关于“未发表”

如果已经发生以下任一情形，应重新判断是否还能填“未发表”：

- 公开网站上线
- 公开代码仓库可访问
- 公开论文或公开展示资料中完整披露软件
- 面向校外公开答辩或公开发布

### 2. 关于权利归属

当前仓库的版权声明是非常重要的证据，但它不是唯一证据。若学校、竞赛主办方、项目任务书或团队内部协议另有约定，应以完整证据链统一后再提交。

### 3. 关于程序鉴别材料

程序鉴别材料已经按真实代码生成。若后续主干代码继续大改，建议重新运行生成脚本，避免登记稿与最终版本不一致。
