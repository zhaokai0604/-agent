# 软著申请材料总目录

本目录按《计算机软件著作权登记办法》第九条至第十一条整理，并结合当前项目实际代码与现有权属声明制作。

官方依据：

- 国家版权局《计算机软件著作权登记办法》  
  https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html

对应条款要点：

- 第九条：申请登记应提交 `申请表 + 软件鉴别材料 + 相关证明文件`
- 第十条：软件鉴别材料包括 `程序鉴别材料 + 文档鉴别材料`
- 第十一条：相关证明文件包括 `申请人身份证明` 以及 `权利归属相关书面材料`

本目录下文件用途如下：

- [01_软件著作权登记申请表_填写稿.md](./01_软件著作权登记申请表_填写稿.md)
  - 按现行软著登记表常用字段整理的填写稿
- [02_软件说明书_文档鉴别材料.md](./02_软件说明书_文档鉴别材料.md)
  - 作为文档鉴别材料使用的《软件使用说明书/软件说明书》
- [03_权利归属与合作开发说明.md](./03_权利归属与合作开发说明.md)
  - 基于当前仓库版权声明整理的权利归属说明稿
- [04_非职务开发说明_模板.md](./04_非职务开发说明_模板.md)
  - 若以个人名义申请时建议同步准备的说明模板
- [05_身份证明与提交清单.md](./05_身份证明与提交清单.md)

## 使用建议

1. 先确认 `申请人/著作权人` 到底是个人、团队成员共同申请，还是学校/公司作为权利人。
2. 若现有权属与学校任务书、竞赛协议或指导老师要求不一致，先统一权属，再提交软著。
3. 若软件已经对外公开发布、公开上线、公开答辩，请同步核对申请表中的 `发表状态` 与 `首次发表日期`。
4. 正式提交前，建议把 Markdown 材料转为 Word 或 PDF 版，并让每位权利人核对姓名、顺序、完成日期和版本号。
