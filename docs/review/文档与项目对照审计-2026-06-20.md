## 二、端口与 Profile（关键，易写错）

| 场景 | Profile | 端口 | 说明 |
|------|---------|------|------|
| 本地开发 | `dev` | **8088 + 8089** | `application-dev.yml` 固定 `app.management.enabled=true` |
| 麒麟生产 | `prod-kylin` | **仅 8088** | `app.management.enabled` 默认 false；Nginx 反代 |
| 管理面隔离 | dev 且 enabled | 8089 | `/admin/**`、`/api/mcp/**`、`/api/assistant/**` 等 |

**前端生产构建必配**（Nginx 同域）：

```bash
VITE_AWARD_LOG_BASE_URL=http://<域名>/award-log
VITE_AWARD_LOG_MANAGEMENT_BASE_URL=http://<域名>/award-log
```

依据：`frontend/src/api/index.js`、`frontend/vite.config.js`。

## 六、部署路径（与脚本一致）

| 步骤 | 命令 / 路径 |
|------|-------------|
| 麒麟首次环境 | `sudo bash scripts/deploy/setup_kylin_host.sh` |
| 龙芯构建 | `bash scripts/deploy/deploy_kylin_loongarch.sh` → `deploy/release-kylin/` |
| 环境变量 | `/etc/threshcore/threshcore.env`（来自 `env.kylin.prod.example`） |
| systemd | `award-log.service`，**User=root**；OS 命令经 `MinPrivilegeExecutor` |
| 验收 | `BASE=http://127.0.0.1:8088/award-log bash smoke_kylin_acceptance.sh` |
| 验收 API | `/api/platform/acceptance`（`deliveryTargetMatch`） |

麒麟 prod 默认：`AGENT_MIN_PRIVILEGE=false`（`env.kylin.prod.example` + `application-kylin.yml`）。
