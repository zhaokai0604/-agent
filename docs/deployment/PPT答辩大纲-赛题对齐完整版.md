### 上屏文字

**页标题**  
`赛题简介：实现目标、价值与技术要求`

**左栏 — 实现目标**

1. 开发部署于**操作系统**的智能运维 **Agent**  
2. 作为**自然语言与 OS 交互的桥梁**  
3. 通过 **MCP（Model Context Protocol）** 协议，使大模型具备：  
   - 感知系统**实时状态**  
   - **采集运维指标**  
   - **执行管理任务**（受控）  
4. **核心挑战**：AI 推理的**不可控性** → 必须设计「安全护栏」架构  

**右栏 — 实用价值**

- 替代零散 Shell，**降低运维门槛**  
- 保留对话效率，同时**可追责、可回放**  
- 面向教育/医疗等行业数据中心，**7×24 稳定**优先于「炫技全自动」  

**底栏 — 整体要求（安全护栏三件套，橙字强调）**

| 组件 | 要点 |
|------|------|
| **意图风险过滤** | 对自然语言指令做风险识别 |
| **最小权限执行代理** | 非必要不用 root |
| **思维链日志审计** | 接收→感知→推理→校验→执行 可追溯 |

**页脚**  
`本作品定位：既能对话高效运维，又能杜绝「误删库、误操作、危险注入」`

### 上屏文字

**页标题**  
`业务场景：从企业运维痛点到赛题演练节点`

**企业背景（左）**

- 场景：企业级数据中心（**教育、医疗**等行业）  
- 典型 OS 问题：**僵尸进程堆积**、**磁盘 I/O 异常**、**配置文件漂移**  
- 现状：依赖复杂脚本 + 监控告警，**门槛高、响应慢**  

**比赛提炼（右）**

- 模拟 **Linux 生产节点**（银河麒麟 V11 + LoongArch）  
- Agent 响应管理员**自然语言诉求**  
- 所有写操作必须经过**安全校验**，不得「模型说什么就执行什么」  

**赛题标杆案例（横条，分 4 格漫画）**

| 步骤 | 管理员 / 系统行为 | 安全要求 |
|------|-------------------|----------|
| ① | 「帮我**清理系统垃圾**」 | 意图进入风险过滤 |
| ② | Agent **环境感知**：发现**大日志文件占满磁盘** | 调用 df/du/journalctl 等 |
| ③ | 执行删除前 **安全校验**：是否**关键库日志**？权限是否合规？ | 路径策略 + 风险评分 |
| ④ | **合规则预览→确认后删除**；**不合规则拒绝**并写审计 | 避免系统崩溃 |

**对比一句（底栏）**  
`传统：脚本删 /var/log/*.log → 误删 MySQL 慢查询日志 → 故障`  
`本作品：感知 → 分类 → 评分 → dry-run → 「确认执行」`

### 上屏文字

| 层次 | 技术 | 职责 |
|------|------|------|
| 展现层 | Vue 3 + Element Plus | 工作台 SSE、MCP 工具台、审计、效果评分 |

**数据流**  
`用户 NL 输入 → 意图路由/Playbook → 感知 Tools → 安全门评分 → 执行/拒绝 → traceId 落库`
