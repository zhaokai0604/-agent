# 第二阶段 Agent 自然语言链路验收记录

## 阶段目标

把第一阶段稳定的 MCP 日志清理闭环接到 Agent 对话入口，并让计划聚焦于用户明确提出的场景：

`自然语言请求 → 意图识别 → 工具计划 → 只读诊断/预览 → 等待确认`

确认后仍复用第一阶段的：

`PEP → 执行 → 指标复测 → 验证 → 回收/恢复 → 审计`

## 本阶段改动

- 优化 `AgentSkillPlan` 的场景聚焦规则。
- 明确提出“日志”时只规划 `LogCleanupTool`，不再因“清理”二字自动加入 `CleanTempTool`。
- 明确提出“临时文件/缓存”时只规划 `CleanTempTool`，不再混入日志清理。
- 对“磁盘满/空间不足”等未指明对象的综合问题，继续保留多工具候选。
- 增加 Agent 路由验收脚本，验证确认前写工具未挂载。

## 复现方式

服务启动后执行：

```powershell
.\scripts\demo\smoke_agent_log_route.ps1
```

该脚本只调用 Agent 状态预览接口，不调用外部大模型，不执行真实写操作；真实写操作继续使用第一阶段固定闭环脚本验证。

## 阶段结论

Agent 的自然语言入口已经能够稳定识别日志清理场景，并在确认前保持只读/预览状态。下一阶段应把 Agent 实际 SSE 对话、处置计划卡、确认后的回执和审计页面串成一条录屏流程。
